# 🍽️ Meal Planner v2

**158+ рецептов** со всего мира. Планировщик на неделю. Автоматический список покупок с ценами Lidl / Continente / Pingo Doce. AI-помощник.

## Запуск на Mac (без Docker)

```bash
cd ~/Downloads/meal-planner-v2   # или путь к папке
npm install
node server.js
```
Открывай: http://localhost:3000  
Девушка: http://192.168.1.XXX:3000 (IP твоего Mac)

## С ANTHROPIC_API_KEY (для AI-чата)

```bash
ANTHROPIC_API_KEY=sk-ant-... node server.js
```

## Docker (если поднимаешь на QNAP или сервере)

```bash
docker compose up -d
```

## Как пользоваться

### 📚 Рецепты
- Фильтры по кухне, методу, категории, времени и сложности
- Клик на карточку → открывается рецепт с ингредиентами и ценами
- Внизу рецепта → добавить в план (выбери день/приём/количество человек)
- "+ В план" на карточке → быстрое добавление

### 📅 Планировщик
- Клик на любую ячейку → выбор рецепта из базы
- Можно заполнить только нужные дни и приёмы пищи
- Переключение недель → ◀ ▶
- Кнопка "Список покупок" → сразу переходишь

### 🛒 Список покупок
- Автогенерируется из плана текущей недели
- Показывает цены в трёх магазинах + оптимальный вариант
- Можно отмечать купленные позиции
- Поле "Дополнительно" — добавь что-то своё

### 🤖 AI-помощник
Кнопка 🤖 справа снизу. Примеры:
- "Составь меню на эту неделю без повторов"
- "Добавь лазанью на пятницу ужин для двоих"
- "Предложи что-нибудь на Air Fryer на вторник"
- "Создай рецепт: куриные котлеты с соусом тарtar"
